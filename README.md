# Sia (SISTEMA DE INDICES, PROVINCIA DE HUANCANE)
## Proyecto SIA
Este proyecto fue iniciado a inicios del 2020, cuando se prohibió que el personal de todas las instituciones no podian salir de casa, por lo que se dicidió escanear los INDICES de los notarios de la provincia de huancane, por lo que se digitalizaron estos documentos y fueron enviados por WhastApp a cada trabajador.  Estos debian enviarlos por el mismo medio, por lo que El Ing. Edgar Apaza Choque (responsable el area de informatica) en esa epoca, se encargó de unir los registros enviados.
## Buscador
Este es un buscador sencillo, escrito en PHP (version 5.6) y que ahora en el 2026, se puede actualizar y cambiarlo mediante clases.
